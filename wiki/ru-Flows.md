# Анализ потоков

Модуль повторяет идеи [Akvorado](https://github.com/akvorado/akvorado) в облегчённом виде: без Kafka и отдельной
оркестрации, с хранением в ClickHouse и консолью внутри панели.

## Конвейер

```
маршрутизаторы, коммутаторы, МСЭ ──NetFlow v5 / v9, IPFIX (UDP 2055) · sFlow v5 (UDP 6343)──► goflow2 ──JSON──►
    обогащение ──batch──► ClickHouse.flows ──materialized views──► flows_5m · flows_1h
```

Экспортёром может быть любое устройство: MikroTik Traffic Flow, Cisco Flexible NetFlow, OPNsense, OpenWrt softflowd,
FortiGate, sFlow HPE / Aruba и другие. Действие **Экспорт потоков** на [странице устройства](ru-Devices.md) настраивает
его.

Обогащение в `flow-collector`:

| Поле | Источник |
|---|---|
| `Direction` | `out` — источник в LAN, `in` — источник снаружи |
| `Route` | `vpn` — next-hop = шлюз (исходящий) или получатель = адрес роутера в LAN (входящий через masquerade); иначе `direct` |
| `LocalAddr` / `RemoteAddr` | Локальная и удалённая стороны с учётом направления |
| `RemoteCountry` | DB-IP City Lite |
| `RemoteAS` / `RemoteASName` | DB-IP ASN Lite |
| `Bytes` / `Packets` | С учётом sampling rate |
| `ExporterAddress`, `InIf`, `OutIf`, `SamplingRate` | адрес экспортёра, ifIndex входящего / исходящего интерфейса, сэмплирование |
| `TCPFlags` | объединение TCP-флагов потока (потоки только с SYN выдают сканирование и SYN flood) |
| `ServicePort` | порт серверной стороны (меньший из двух), основа измерения `Application` |

`Direction = internal` — трафик между двумя локальными адресами (между VLAN, LAN ↔ сервер); отключается
`KEEP_INTERNAL=0` у коллектора. Локальные сети — `LAN_CIDR`, все частные подсети IPv4 и префиксы IPv6 (/48–/64) с
интерфейсов управляемых устройств (обновляются раз в минуту); уникальные локальные (`fc00::/7`) и link-local
(`fe80::/10`) адреса IPv6 всегда локальные. Исключаются: транспорт туннеля к VPS, multicast/broadcast.

Потоки IPv4 и IPv6 собираются одинаково. Адреса хранятся в колонках `IPv6` (IPv4 — как `::ffff:a.b.c.d`) и показываются
в привычном виде; установка, обновлённая с 2.0, преобразует таблицы при первом запуске.
Атрибуция сайтов выполняется при запросе через словарь ClickHouse `sites` (`ip_trie`), который заполняется при
загрузке `ip-list.json` и добавлении своих подсетей — поэтому новое разбиение применяется и к старым данным.

Имена берутся из словарей ClickHouse, которые раз в 2 минуты обновляются из реестра устройств: `exporters` (адрес
экспортёра → устройство), `if_names` (экспортёр + ifIndex → имя и скорость интерфейса), `hosts` (адрес LAN → имя
клиента), `ptr` (удалённый адрес → обратный DNS для 300 самых активных адресов за час, раз в 10 минут) и `threats`
(публичные списки угроз, см. ниже).

## Обзор

Потоки в секунду, время последнего потока, доля трафика через VPN за 24 ч, объём базы; график за 24 часа;
топ сайтов, AS, стран, протоколов, удалённых портов, устройств LAN, приложений, экспортёров и контактов с угрозами за
час; последний поток со всеми полями.

## Визуализация

| Параметр | Значения |
|---|---|
| Период | 15 мин … 1 год, произвольный интервал, сдвиг назад/вперёд, отдаление, автообновление (10 с – 5 мин) |
| Измерения | до 6, порядок меняется, кнопка разворота порядка |
| Лимит | 1–50 серий, остальное — «Прочее» |
| Топ по | среднему (`avg`), пикам (`max`), последним значениям (`last`) |
| Единицы | бит/с, пакетов/с, потоков/с |
| График | Stacked, 100%, Lines, Grid (малые графики), Sankey |
| Двунаправленный | входящий трафик отображается отрицательными значениями |
| Прошлый период | пунктир «всего» за предыдущий час / день / неделю / месяц / год |

Таблица под графиком: минимум, максимум, последнее, среднее, 95-й перцентиль, итог (байты / пакеты / потоки).
Все параметры сохраняются в URL — ссылкой можно поделиться. `Ctrl+Enter` — применить.

### Измерения

`Direction`, `Route`, `LocalAddr`, `LocalHost` (имя клиента), `RemoteAddr`, `RemoteNet` (/24 для IPv4, /64 для IPv6), `RemoteHost` (PTR),
`RemoteAS`, `RemoteASName`, `RemoteCountry`, `Site`, `SiteGroup`, `Threat`, `Proto`, `Application`, `ServicePort`,
`LocalPort`, `RemotePort`, `TCPFlags`, `Exporter`, `ExporterName`, `InIfName`, `OutIfName`.

### Агрегаты

Кроме сырой таблицы `flows` (`FLOWS_TTL_DAYS`, 30 дней) ClickHouse хранит `flows_5m` (90 дней) и `flows_1h` (2 года) —
таблицы SummingMergeTree, которые заполняют materialized views по измерениям с небольшим числом значений (направление,
маршрут, экспортёр и интерфейсы, локальный адрес, AS, страна, протокол, порт сервиса). Запрос дольше суток, все
измерения и поля фильтра которого есть в агрегатах, выполняется по `flows_5m`, дольше недели — по `flows_1h`; на
графике видно, какая таблица использована. При обновлении агрегаты заполняются из уже собранных потоков.

### Представления

Всё состояние визуализации (период, измерения, фильтр, график) сохраняется под именем и доступно всем.

## Язык фильтров

```
условие  := Поле оператор значение | Поле IN (значение, ...) | Поле NOTIN (значение, ...)
выражение := условие | NOT выражение | (выражение) | выражение AND выражение | выражение OR выражение
```

| Тип поля | Операторы | Значения |
|---|---|---|
| Адрес (`LocalAddr`, `RemoteAddr`, `RemoteNet`, `Exporter`) | `=`, `!=` | `203.0.113.5`, `203.0.113.0/24`, `2001:db8::5`, `2001:db8::/48` |
| AS (`RemoteAS`) | `=`, `!=`, `<`, `<=`, `>`, `>=`, `IN` | `AS13335` или `13335` |
| Порт, протокол | числовые, `IN` | `443`; протокол — `tcp`, `udp`, `icmp` или номер |
| Строки (`Site`, `RemoteCountry`, `RemoteASName`, `SiteGroup`) и `Direction`, `Route` | `=`, `!=`, `IN`, `NOTIN`, `LIKE`, `UNLIKE`, `ILIKE`, `IUNLIKE` | `vpn`, `'%google%'` |

Имена полей нечувствительны к регистру, строки — в одинарных или двойных кавычках, комментарии `--` и `/* */`.
Все значения передаются в ClickHouse параметрами.

Примеры:

```
Route = vpn AND RemoteCountry IN (US, NL)
Site LIKE '%google%' AND NOT Proto = udp
Direction = out AND LocalAddr = 192.168.0.50
RemoteAS = AS13335 OR RemoteASName ILIKE '%cloudflare%'
Route = direct AND SiteGroup = video   -- сайты из списка, ушедшие мимо VPN
```

### Сохранённые фильтры

Фильтр можно сохранить с названием; сохранённые фильтры видны всем операторам. Удалить может автор или администратор.

## Потоки

Таблица последних 200 потоков за час с фильтром и автообновлением: имя клиента, PTR, приложение,
TCP-флаги, экспортёр и интерфейсы, список угроз.

## Экспортёры

Все устройства, присылавшие потоки за 24 часа: имя из реестра устройств, потоков в секунду, трафик, сэмплирование,
последний поток и по каждому интерфейсу — входящая и исходящая скорость за 5 минут, скорость порта и загрузка.

## Правила обнаружения

Правила проверяет процесс-лидер каждую минуту; сработавшая группа поднимает алерт (и сообщение в Telegram) со
ссылкой **Трафик** на нужную визуализацию и снимается после `clear_count` проверок без нарушения.

| Тип | Условие (по умолчанию) |
|---|---|
| Порог трафика | любые измерения, бит/с или пак/с `>` или `<` порога за окно |
| DDoS: объёмная атака | входящие ≥ 500 Мбит/с или ≥ 100 тыс. пак/с на один локальный адрес за 60 с, при желании — выше k × его трафика за прошлый час |
| DDoS: SYN flood | пакеты SYN без ACK ≥ 2000 пак/с и ≥ 60 % TCP-пакетов на один локальный адрес |
| Сканирование | входящее: удалённый адрес обращается к ≥ 100 портам или ≥ 50 локальным адресам за 5 мин; исходящее: локальное устройство обращается к ≥ 50 адресам (заражённое устройство) |
| Аномалия относительно недели | последние 5 минут отличаются от медианы того же времени прошлых недель больше чем на max(k × 1,4826 × MAD, ratio × медиана) |
| Падение трафика | последние 5 минут ниже `ratio` × обычного трафика в это время |
| Экспортёр молчит | экспортёр, видимый за сутки, не присылает потоков N минут |
| Контакт с угрозой | трафик с адресом из списков угроз |
| Загрузка канала | скорость интерфейса ≥ N % его скорости (скорость — из реестра устройств) |

У правила есть фильтр на языке визуализации, важность и счётчики *срабатывания* (сколько проверок подряд) и *снятия*.
**Проверить** выполняет правило сейчас и показывает группы, которые сработали бы. При первом запуске создаются пять
правил (объёмная DDoS, SYN flood, контакт с угрозой, сканирование — выключено, молчащий экспортёр).

## Угрозы

Публичные списки скачиваются раз в `threat_refresh_hours` (6) ч в словарь `threats`: FireHOL level1, Spamhaus DROP,
abuse.ch Feodo Tracker (CINS Army доступен, выключен по умолчанию). Частные, зарезервированные и multicast-диапазоны,
`LAN_CIDR` и сети из `threat_exclude` никогда не помечаются. Вкладка **Угрозы** показывает локальные устройства,
обменивавшиеся трафиком с адресами из списков; измерение `Threat` и правило «Контакт с угрозой» используют те же
данные.

## Ресурсы

ClickHouse ограничен 768 МБ памяти, системные журналы отключены, сырые потоки хранятся `FLOWS_TTL_DAYS` дней, 5-минутные агрегаты — 90 дней, часовые — 2 года.
Для домашней сети это десятки мегабайт в сутки.
