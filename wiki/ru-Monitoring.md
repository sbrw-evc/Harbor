# Мониторинг и алерты

## Обзор

- KPI: онлайн, клиенты, трафик за сегодня / 7 / 30 дней, текущая скорость.
- Состояние: VPN-сервер, домашний шлюз, маршрут на MikroTik, открытые алерты.
- Live-график пропускной способности (обновляется по SSE при каждом опросе сервера).
- Статусы клиентов, топ по трафику, последние подключения.

Все страницы обновляются сами: события сервера (`live`, `clients`, `alert`, `audit`, `connection`) инвалидируют
соответствующие данные, плюс фоновое обновление раз в 30 секунд и при возврате на вкладку.

## Аналитика

Трафик через VPN за 1 ч – 90 дней, топ клиентов, тепловая карта активности по часам и дням недели,
подключения по странам, экспорт CSV.

## Карта подключений

Точки — места, откуда клиенты подключались (по IP endpoint), размер — число подключений; зелёные — клиенты онлайн;
жёлтая — сервер. Тайлы OpenStreetMap идут через кэширующий прокси панели (`/tiles`) с идентифицирующим
User-Agent — браузеры не обращаются к серверам OSM напрямую. Геолокация — DB-IP Lite (обновляется ежемесячно).

## Алерты

| Ключ | Важность | Условие |
|---|---|---|
| `server.unreachable` | критично | Нет SSH-доступа к VPS / к контейнеру AmneziaWG |
| `gateway.stale.*` | критично | Нет handshake домашнего шлюза дольше порога |
| `router.tunnel_down` | критично | Маршрут через туннель на MikroTik неактивен (работает резервный) |
| `router.unreachable` | внимание | Нет SSH-доступа к MikroTik |
| `openbao.down` | критично | OpenBao недоступен или запечатан |
| `client.quota_warn.*` | внимание | Использован порог квоты |
| `client.quota.*` | внимание | Квота исчерпана, клиент заблокирован |
| `client.expiring.*` | инфо | Скоро окончание доступа |
| `client.expired.*` | инфо | Срок истёк, клиент заблокирован |

Алерты дедуплицируются по ключу и закрываются автоматически при восстановлении. Их можно «принять».

## Уведомления в приложении

Все сообщения панели — результаты действий, ошибки входа и загрузки данных, алерты сервера — показываются
всплывающими уведомлениями в правом нижнем углу: одновременно не более 5, исчезают сами (успешные — через 4 с,
ошибки — через 9 с), закрываются крестиком. Повторяющиеся ошибки фоновых обновлений не дублируются.

Колокольчик в нижней части боковой панели открывает **центр уведомлений**: история последних 100 сообщений
(хранится в браузере), счётчик непрочитанных, фильтр по типу, отметка «прочитано» и очистка.

## Telegram

1. Создайте бота у @BotFather.
2. **Настройки → Telegram-бот** — вставьте токен (проверяется через `getMe` и сохраняется в OpenBao).
3. Укажите chat id (пользователя, группы или канала), включите уведомления и выберите минимальную важность.
4. «Тестовое сообщение» — проверка.

Отправляются новые алерты не ниже выбранной важности и сообщения о решении критичных.
