# VPN на MikroTik

[English](MikroTik-VPN.md) · **Русский**

Помимо сервера Amnezia на VPS панель управляет WireGuard-сервером на домашнем MikroTik (RouterOS 7).
Его клиенты — обычные клиенты панели: создание, блокировка, квоты, сроки доступа, трафик, карта подключений,
QR-коды и одноразовые ссылки работают так же, как для клиентов Amnezia.

| | Amnezia (VPS) | MikroTik (дом) |
|---|---|---|
| Протокол | AmneziaWG (с обфускацией) | WireGuard |
| Выход в интернет | VPS | Домашний провайдер; сайты из списка — через Amnezia |
| Доступ к домашней сети | — | Есть |
| Приложения | AmneziaWG, Amnezia VPN (`vpn://`) | WireGuard, Amnezia VPN (QR или `.conf`) |

## Настройка

Откройте **VPN на MikroTik** и нажмите **Настроить на MikroTik** (администратор). Панель идемпотентно создаёт:

| Объект | Значение |
|---|---|
| Интерфейс WireGuard | `wg-ac`, порт `51820/udp`, MTU 1420, комментарий `network-control` |
| Адрес | `10.9.0.1/24` на `wg-ac` |
| Firewall input | `amnezia: wireguard` (UDP 51820), `amnezia: wireguard dns udp/tcp` (DNS с `wg-ac`) |
| Mangle | `amnezia: mark new wg conns to vpn-sites`, `amnezia: route wg conns via tunnel` |

Существующие правила не меняются; повторная настройка только добавляет недостающее. Интерфейс, сеть и порт
задаются `MT_WG_IFACE`, `MT_WG_NETWORK`, `MT_WG_PORT` (см. [Конфигурация](ru-Configuration.md)).

У роутера должен быть публичный IP на WAN (или проброс порта к нему), иначе клиенты из интернета не подключатся.

## Параметры клиентских конфигов

| Настройка | По умолчанию | Описание |
|---|---|---|
| Адрес подключения | публичный IP роутера (`/ip cloud` или адрес WAN) | Можно указать домен |
| DNS | `10.9.0.1` (DNS роутера) | Тот же DNS, что у устройств в LAN, — доменные правила [маршрутизации](ru-Routing.md) совпадают |
| AllowedIPs | `0.0.0.0/0` | Пресет «Только домашняя сеть»: `LAN_CIDR, MT_WG_NETWORK` |

Изменения действуют для конфигов, скачанных после сохранения; уже выданные конфиги сохраняют старые значения.

## Создание клиента

**Клиенты VPN → Новый клиент → VPN-сервер: MikroTik (WireGuard)**. Панель генерирует ключи и отдельный
preshared key (оба хранятся в OpenBao), выделяет следующий свободный адрес в `10.9.0.0/24` и добавляет пир
с комментарием `network-control: <имя>`. Пиры, добавленные на роутере вручную, импортируются кнопкой
**Синхронизировать** (без закрытого ключа — перевыпустите ключи, чтобы получить конфиг).

## Трафик

Панель опрашивает `/interface wireguard peers` с тем же интервалом, что и сервер Amnezia: rx/tx, последний handshake,
адрес подключения. Трафик клиентов `10.9.0.0/24` виден и в [анализе потоков](ru-Flows.md) — сеть добавлена
к локальным сетям коллектора.

## Откат

`mikrotik/network-control-remove.rsc` удаляет интерфейс WireGuard, его пиры, адрес и правила вместе с остальными
объектами панели.
